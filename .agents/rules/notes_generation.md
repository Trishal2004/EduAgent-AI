# Notes Generation Rule

When the user requests notes, generate comprehensive educational notes covering all relevant concepts from the selected document/topic. 
- Do not produce merely a brief summary. 
- Explain concepts clearly and sufficiently.
- Include definitions, principles, mechanisms, classifications, step-by-step processes, examples, formulas, applications, advantages, disadvantages, comparisons, and exam-relevant points whenever applicable. 
- Use the uploaded study material as the primary source.
- Do not invent unsupported information.
